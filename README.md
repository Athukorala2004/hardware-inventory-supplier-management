# Supplier Management Module

## Smart Hardware Inventory Management System

This repository documents my individual contribution to a six-member university group project developed at SLIIT.

**My Responsibility:** Supplier Management

## Project Overview

The Smart Hardware Inventory Management System is a full-stack mobile application designed to manage hardware inventory operations, including products, orders, suppliers, notices, tasks and repairs.

## Technologies

- Node.js
- Express.js
- MongoDB and Mongoose
- REST APIs
- React Native and Expo (overall mobile application)

## Supplier Management Features

The module supports:

- Creating new supplier records
- Viewing supplier information
- Updating existing supplier details
- Deactivating supplier records
- Managing supplier-related documents and contracts

## Backend Structure

The supplier module in the original project contains:

- **Controller:** Supplier request-handling logic
- **Model:** Supplier data schema
- **Routes:** Supplier API endpoints

## My Contribution

I was responsible for developing the Supplier Management module, including supplier record operations and the associated backend functionality.
